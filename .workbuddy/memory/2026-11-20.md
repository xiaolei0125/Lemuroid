# 2026-11-20 工作日志

## Lemuroid 在魔百盒（device-protected storage）闪退修复

**背景**：Lemuroid 1.17.0 在 CM311-1a-YST（江苏移动魔百盒，Android 9，192.168.5.60:5555）上 100% 闪退。根因是该定制 ROM 把第三方应用 dataDir 统一放到 `/data/user_de/0`（device-protected storage），`isDeviceProtectedStorage()` 恒为 true，WorkManager 2.9.0 构造函数无条件抛 `IllegalStateException("Cannot initialize WorkManager in direct boot mode")`，崩溃于 `Application.onCreate`。

**修复方案**：让 WorkManager 惰性、可安全降级。
- 新增 `WorkManagerGuard.kt`（`app/utils/android/`）：检测 `isDeviceProtectedStorage`，不可用时 `getInstanceOrNull` 返回 null，空 Flow 替代。
- `MainProcessInitializer` 移除对 `WorkManagerInitializer` 的依赖（崩溃直接触发点）。
- 所有 `WorkManager.getInstance()` 调用点（SaveSyncWork、LibraryIndexScheduler、PendingOperationsMonitor、CacheCleanerWork、ChannelUpdateWork）改为经 `WorkManagerGuard` 空安全调用。

**构建方案**：不本地编译，改用 GitHub Actions。新增 `.github/workflows/build-tvbox.yml`：push master / workflow_dispatch 触发，构建 `freeBundleDebug`（包名 `com.swordfish.lemuroid.debug`，仓库自带 debug.keystore 签名，无需 secret），产物上传为 artifact。

**仓库**：`https://github.com/xiaolei0125/Lemuroid.git`（fork），分支 master。修改已 commit（af95fc7）并 push。

**关键约定/注意**：
- 变体名：flavor 组合 `opensource`(free/play) × `cores`(bundle/dynamic)；`freeBundle`=单APK含全部核心；`freeDynamic`=动态下载核心。
- debug 变体 applicationIdSuffix=".debug" → 包名 `com.swordfish.lemuroid.debug`，与原版 `com.swordfish.lemuroid` 不同，需卸载原版或并存。
- release 构建需 `release.jks`（secret），仓库里没有。
- `lemuroid-cores` 是 git submodule，GitHub Actions 用 `submodules: recursive` 自动拉取。
